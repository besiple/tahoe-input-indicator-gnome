# macOS Tahoe Input Indicator for GNOME Shell

A lightweight GNOME Shell extension (GNOME 45–51+) providing a floating input source indicator with text caret tracking and instant switching without the modal center switcher popup.

## Overview

- **Caret-Aware Positioning**: Displays a compact floating pill right next to your active text caret when typing, with automatic fallback to the mouse cursor position.
- **Zero-Latency Switching**: Eliminates the default full-screen modal switcher popup, providing immediate layout changes.
- **Smooth Animations**: Uses smooth ease-in / ease-out transitions with rapid-switch pulsing.
- **Modern Glass Aesthetics**: Styled with frosted glass translucent container, clean typography, and boundary clamping.

## Installation

```bash
git clone https://github.com/besiple/tahoe-input-indicator-gnome.git
cd tahoe-input-indicator-gnome
./install.sh
```

## Removal

```bash
./uninstall.sh
```
